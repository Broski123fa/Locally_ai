CHROMEBOOK SETUP

Prepare for offline use

You do not need Python, Linux, or SSH. Chrome needs a one-time online setup so it can keep the app and model in this browser.

  1. Open this app in Chrome while online. Use its secure web address; do not open index.html directly from the Files app.
  2. Install the app from Chrome's menu if the install option is available. This keeps the app screen available offline.
  3. Load the model and wait for Ready. The first model load needs about 3.4 GB of model files and additional working memory.
  4. Test it before you need it. Turn off Wi-Fi, reopen the app, and send a test message. Keep enough free storage and do not clear Chrome site data.

Offline storage is tied to this Chrome profile and this app's web address. Chromebook hardware must support WebGPU and have enough memory to run the 3B model.
